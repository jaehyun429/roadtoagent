# 확인된 것
# - 모델은 재개 메시지대로 실패한 도구를 같은 인자(course=딥러닝, limit=1)로 다시 불렀다.

# - LOGIN_FAILED 는 같은 코드 경로(PAUSE_ERRORS)로 멈춘다. 다만 실제 비밀번호 오류로 재현하면 학교 계정 잠금 위험이 있어
#   로그인 URL을 틀리게 주는 방법으로 시험했는데, 그 경우 서버는 LOGIN_FAILED 가 아니라 PARSING_FAILED 를 돌려줬다
#   (login() 안의 폼 파싱 단계에서 실패). 이 분류를 LOGIN_FAILED 로 볼지는 01 서버 F2 설계에서 정할 일.
